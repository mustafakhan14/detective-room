# One-Room 2.5D Detective Prototype

This repo contains a fresh Unity prototype scene for a small 2.5D detective room.

Repository: https://github.com/mustafakhan14/unitylearning

## Open and Run

1. Install Unity Hub and Unity Editor `6000.5.4f1` or newer if you do not already have Unity installed.
2. Open the cloned repository root as a Unity project.
3. Open `Assets/Scenes/DetectiveRoom.unity`.
4. Press Play.

If Unity Hub warns about a missing editor version, choose the installed `6000.5.4f1` editor. This prototype uses only basic built-in 3D, UI, and physics APIs, so it does not need the older `2022.3.62f1` editor.

The room is generated by `DetectiveRoomBootstrap` so the scene stays small and the implementation is easy to study.

## Prototype Loop

- Click the floor to move the detective.
- Hover objects to see prompts.
- Click `Broken Glass`, `Ledger`, and `Locked Door` to add evidence.
- Click the `Radio Dispatcher` for a short dialogue interaction.
- The objective completes after all required evidence is recorded.

## Learning Map

- `PlayerClickMover` handles click-to-move.
- `Interactable` defines clue/dialogue data exposed in the Inspector.
- `InteractionController` turns cursor hits into inspections or dialogue.
- `EvidenceLog` records clue IDs once.
- `DialoguePanel` and `InspectionPanel` manage UI panels.
- `GameObjective` checks the room completion condition.
- `DetectiveRoomBootstrap` creates the room, camera, lighting, props, and UI.
